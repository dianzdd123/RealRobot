This repository contains the official implementation of an **Occlusion-Aware Robotic Grasping System**. By integrating **YOLOV8** and **SAM2 (Segment Anything Model 2)** for high-fidelity perception and **GPT-4o** for strategic reasoning, the system autonomously identifies, reasons about, and resolves occlusions in complex, cluttered tabletop environments.

## Repository Structure & File Descriptions

### Main Scripts

* `robot_with_occ.py`: Main entry point featuring occlusion-aware reasoning.
* `robot.py`: Baseline grasping pipeline without occlusion handling.

### Core Utilities (`/utils`)

| File | Function |
| :--- | :--- |
| `occluded.py` | Detects depth and proximity occlusions to identify blocking objects. |
| `affordance_area.py` | Refines grasp regions using the striped pruning algorithm. |
| `rotate.py` | Calculates grasp orientation and width using PCA-based geometry analysis. |
| `API.py` | Handles LLM-based instruction parsing and task grounding. |
| `yolo_utils.py` | Manages object discovery and 3D instance deduplication. |
| `sam2_utils.py` | Provides pixel-accurate instance segmentation using SAM2. |
| `camera_to_world.py` | Performs kinematic transformation to the robot base frame. |
| `coordinate.py` | Deprojects 2D pixels to 3D camera coordinates using intrinsics. |
| `save_json.py` | Generates structured scene representations for LLM conditioning. |
| `voice_hybrid.py` | Provides a hybrid voice (PTT) and text command interface. |
| `traj_execute.py` | Executes motion primitives on the physical xArm hardware. |


| Directory | Description |
| :--- | :--- |
| `test_imgs/` | Static test dataset containing raw RGB-D observations and pipeline stage visualizations. |

To support perception and tracking evaluation, the following file formats are used:

* **`.png`**: Raw RGB scene capture.
* **`.npz`**: Compressed 3D depth data synchronized with the RGB frame.
* **`_depth.png`**: Visualized depth map for sensing reliability analysis.
* **`_boxed.png`**: Bounding box localization results from the YOLO detector.
* **`_sam2_masks_with_centers.png`**: Instance segmentation masks and geometric centers generated by SAM2.
